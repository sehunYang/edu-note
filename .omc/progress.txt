# QC v1 세팅실 — Ralph 진행 로그

## 검증 게이트 (확정)
- DB 도달 확인됨(Supabase pooler, public 37 tables). DATABASE_URL in .env.local.
- itest 실행: `RUN_DB_ITEST=1 node --env-file=.env.local ./node_modules/vitest/vitest.mjs run <file>`
- migrate 실행: `node --env-file=.env.local ./node_modules/drizzle-kit/bin.cjs migrate` (generate: ./node_modules/drizzle-kit/bin.cjs generate)
- 단위테스트: `npm test` (vitest, include lib/**/*.test.ts, server-only stub alias)

## 코드베이스 패턴
- 쿼리: lib/db/queries/*.ts, DB=PostgresJsDatabase<typeof schema>, ownerId 인자. index.ts 에서 export *.
- 스키마: lib/db/schema/{enums,identity,classes,misc,records,attendance,_shared}.ts. _shared: pk()/ownerId()/timestamps(). casing snake_case.
- itest 패턴: postgres(DATABASE_URL,{prepare:false,max:1}) + drizzle(sql,{schema,casing:'snake_case'}), owner=randomUUID(), afterAll 정리. describe.skipIf(!RUN).
- teacherProfile 단일행(ownerId unique). setupState(owner,feature,completedAt) unique(owner,feature).
- calendarEvents: 기존 source(neis/manual/personal/task)+ccaArea+title+date. (eventKind 등은 C3에서 추가)
- studentYears: sid char(5), grade/classNo/number 컬럼 이미 존재. persons↔studentYears, yearLinks(linkStatus,candidatePersonId,resolvedAt).
- subjects: jipilMid/FinalWeight numeric, examBoundaryDate date, performanceItems(name,weight). courseSections(label,examBoundaryDate), enrollments unique(section,studentYear).
