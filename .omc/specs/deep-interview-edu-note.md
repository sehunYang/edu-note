## 1. Goal (목표)

고등학교 교사(담임 겸 교과 교사) 1인을 위한, **공간(`~실`) 기반 UI의 다기기 클라우드 웹앱**. 학교/집/휴대폰 어디서든 단일 사용자로 접속해 **교수–수업–평가–기록(교수평기)을 일체화**한다. 강제 팝업 넛지로 일상 기록을 유도하고, 누적된 관찰기록·수행평가·활동기록을 바탕으로 **Claude API로 5종 특기사항(교과세특/행동발달/자율/동아리/진로) 초안을 생성**하며, 외부 공공 API(학사일정·급식)와 컴시간알리미(시간표)를 적극 연동한다. 학생 개인정보(명렬·성적·상담·출결)를 다루므로 **보안과 처음부터의 완전한 데이터 모델 설계**를 최우선으로 한다.

## 3. Constraints (제약)

- **사용자**: 단일 교사(고등학교 담임 겸 교과). 멀티테넌트 아님.
- **배포**: 다기기(학교PC·집·폰) 접속, 클라우드 동기화, **오프라인 미지원**(항상 온라인 가정).
- **데이터 위치**: 학생 PII → **국내(서울 리전) 저장**.
- **호스팅**: **무료티어 우선**(강제). DB 무료티어.
- **AI**: **Claude API** (사용량 과금 수용). 호출은 **전부 서버 사이드**(키 브라우저 비노출).
- **인증**: **Google OAuth, 본인 계정만 허용**.
- **대량 데이터 입력**: 전부 **CSV 업로드 → DB**.
- **외부 API: 읽기 전용.** NEIS 쓰기 불가 → Edu_Note에서 정리 후 교사가 NEIS에 **수기 이관**.
- **식별자**: 학번 = 학년(1)+반(2)+번호(2) = 5자리(예 1학년5반23번=`10523`), **연도 내 유일**. 내부적으로 학번과 별개의 **영속 학생 ID** 존재.
- **바이트 규칙**(특기사항): 영문/숫자/특수/공백=1, 줄바꿈=2, 한글=3 Byte.
- **바이트 상한**(실제 NEIS의 2배, 초안 여유용): 자율 3000 · 동아리 3000 · 진로 4200 · 교과세특 3000 · 행동발달 3000.
- **기능 게이트**: 담임반·수업·동아리 기능은 **초기 세팅 완료 후에만 활성화**.
- **추천 스택**(plan 합의에서 아키텍트가 최종 확정): Next.js+TypeScript / 서울 리전 관리형 PostgreSQL(예: Supabase ap-northeast-2) + RLS / Google OAuth / 서버사이드 AI·외부호출 / 일일 cron 동기화. 전부 무료티어 가용.

## 5. Acceptance Criteria (테스트 가능 기준)

### AC-A 기반 플랫폼
- [ ] Google OAuth로 지정된 본인 계정만 로그인된다(타 계정 거부).
- [ ] 외부 데이터는 서울 리전 DB에 저장되고, Claude/외부 API 키는 클라이언트 번들에 존재하지 않는다.
- [ ] "새 학년 시작" 버튼으로 연도 단위 데이터를 갱신하며, 학번(5자리)은 연도 내 유일 키로 강제된다.
- [ ] 한 학생이 담임반·수업반·동아리에 동시 등장 시 **학번으로 동일인 통합**된다.
- [ ] 연도 전환 시 **이름 기반 매핑**으로 작년 기록을 영속 학생에 연결: 유일 매칭은 자동, **동명이인은 보류(pending)→수동 매핑**(작년 반/번호·진로를 함께 표시), 매칭 없으면 비움.
- [ ] 담임반·수업·동아리 기능은 초기 세팅 전 **잠금**, 세팅 완료 후 활성화된다.
- [ ] CSV 업로드: 학생 기본(필수=번호·이름, 선택=전화·부모·진로 등 추후 추가), 수업명단(학년·반·번호·이름), 동아리부원(학번·이름·희망진로), 학급역할(역할명·하는일·학번·이름·봉사시간유무), 수행평가(학번·평가명·점수·줄글내용)가 각각 정상 처리된다.

### AC-B 수업 운영 & 시수
- [ ] 한 과목이 여러 수업반으로 분할되고 반별로 구분된다(예: 물리학→2-7·2-9·2-10).
- [ ] 시간표는 컴시간알리미에서 **매일 1회 동기화**되어 변경분만 반영하고, 데이터 미수신·전무 시 **캘린더에 경고** 후 수기 입력이 가능하다.
- [ ] 이번 학기 **총/진행/남은 차시**(시험 전까지)가 지속 카운트되고, **"수업 미진행" 버튼**으로 불이행이 별도 집계되어 남은 차시에 반영된다.
- [ ] 과목 생성 시 **2022 개정 전 과목 프리셋**에서 선택하면 평가방식이 자동 결정되고, **"개별 작성"** 으로 프리셋 외 과목의 평가방식을 직접 지정할 수 있다.
- [ ] 평가설정(선택, 추후 추가 가능): **수행평가 요소(복수)+각 반영비율**, **지필 반영비율(중간/기말 — 둘다/하나만/없음)**, **평가방식(상대+절대 / 절대만 / 성취도3단계)**.

### AC-C 관찰기록 & AI 세특
- [ ] 현재 시각 기준 **지나간 미기록 수업**이 있으면 강제 팝업이 뜨고, 기록 전에는 사라지지 않는다(스누즈 없음 — 의도된 마찰).
- [ ] 수업당 **2명** 기록: ①**가중 랜덤**(기록량 적은 학생 우선) ②**교사 직접 선택**.
- [ ] 교과 관찰기록 = `관찰날짜 + 자유서술 + 교과키워드(진로·태도·탐구·개념·문제·실험·표현·협업, 중복 허용)`, 영속 학생에 종속 저장.
- [ ] 담임 행동특성 = **매일 16시 이후 팝업**, 학생 선택 후 `날짜 + 서술 + 행특키워드(배려·협력·공동체·성실·회복·리더쉽·변화, 중복 허용)`. 교과 스트림과 분리.
- [ ] AI 세특 초안: 입력(학생 진로 + 수행평가 + 관찰기록 + 학생페이지 추가메모) → **`세특 작성 지침.md`** 문체 적용 → **Claude API 서버사이드 호출** → 초안 생성.
- [ ] 초안은 앱 내 편집 가능하고, **바이트 카운터**가 규칙(한글3·영숫특공백1·줄바꿈2)과 유형별 상한(자율/동아리/진로/교과세특/행동발달)을 표시·강제한다.
- [ ] 생성 결과는 **CSV로 출력**된다.

### AC-D 동아리실 (2단계)
- [ ] 부원 CSV(학번·이름·희망진로) 업로드, 영속 학생에 연결.
- [ ] 캘린더의 동아리 활동일 기준 **활동일 1주 전부터 미작성 시 계속 팝업**.
- [ ] 활동기록은 **공통 내용이 전원 기본 적용 + 학생별 개별 수정** 가능.
- [ ] 동아리 세특 = C와 동일 구조(단 **활동기록 중심**), Claude API → CSV.

### AC-E 학사일정 & 캘린더
- [ ] 캘린더가 **공공 API 학사일정 + 교사 수동 일정 + 개인 일정 + 업무 데드라인**을 일괄 표시.
- [ ] 학사일정은 **창체 4영역(자율·동아리·진로·봉사)** 으로 분류된다.
- [ ] **ICS 임포트** 지원.
- [ ] 자율/진로 입력: 담임교실 **학생 활동 기입란** + 태그(자율/진로); 둘 다 선택 시 AI 세특 작성 때 **한 곳에만** 배치.
- [ ] 봉사: 학급공통(학사일정)·개별(학급역할 CSV)·동아리 3종 구분, **시간 미추적**·정량강조 금지, 정성 내용만 자율활동 참조.

### AC-F 출결
- [ ] 출결 = **사유(질병/인정/미인정/기타) × 성격(지각/조퇴/결과/결석)** 조합으로 기록(담임 일일 출결 핵심, 교과 출결은 체크 수준).
- [ ] 신고서는 **제출 여부 마킹만**(서류 업로드 없음 — 학교가 NEIS로 수령).
- [ ] 신고서 필요 규칙: **결석=항상**; 조퇴/지각/결과=**인정 사유 또는 사유 '생리통'일 때만**; 교외체험학습=**사후보고서**(신청서는 추적 안 함).
- [ ] 기한 추적 = **수업일(공휴일·주말 제외) 5일**; 에스컬레이션 **정상(≤3) → 위험(>3, 강조) → 심각(>5, 최고강조·해결까지 상시)**, 미제출건은 오늘의학교에 지속 표시.
- [ ] 출결 입력 = **날짜별 마킹 기본 + 전환 버튼으로 학생별**.

### AC-G 상담실 (2단계)
- [ ] 상담일지(학생+학부모) = `날짜 + 내용`, 영속 학생 종속 누적.
- [ ] **AI 분석은 더미데이터 목업**으로 막아두고 UI만 노출.

### AC-H 교무실 (2단계)
- [ ] 업무 = 데드라인 to-do + 진척도 시각화, 캘린더에 표시.
- [ ] 예산 = 초기세팅 **영역·총액** → 지출 기입 → **잔액 실시간** 계산.

### AC-K 오늘의학교(1단계) / 통계·인쇄실(2단계)
- [ ] 오늘의학교: 당일 수업/출결/기록 넛지(미기록 수업, 16시후 행특, 미제출 신고서, 동아리 미작성)를 통합 표시.
- [ ] 통계실: 학생별 통합 조회(성적추이·출결·상담), 연도 간 **성장 그래프**. **성적은 목업**.
- [ ] 상대위치 표기 = **과목 전체 석차 + 등급(2022개정 5등급제) + 성취도(A~E, 성취도 컷 과목별 명시)**, 단 과목 평가방식에 따라 표기 항목 결정.
- [ ] 인쇄실: 학생 종합카드·상담기록·출결통계 등을 **선택 출력**.

### AC-I 공지실 (2단계)
- [ ] 내부 공지 기입·아카이빙.
- [ ] **학생별 개별 토큰 링크**(128비트+ 추측불가, 비밀번호 없음, HTTPS, noindex, **재발급/폐기** 가능).
- [ ] 링크 일괄 배포용 **CSV 출력(학번·이름·링크)**.
- [ ] 공개페이지 = **공통칸**(이번주 할일[학사일정]·교사 한마디·시간표·급식) + **개별칸**(본인 출결 상태·성적·교사 개별 메시지), 읽기 전용.

### AC-J 외부 연동
- [ ] 나이스 교육정보 개방포털 **학사일정·급식 OpenAPI** 연동(읽기, 인증키).
- [ ] 컴시간알리미 시간표 연동(비공식) + 실패 시 수기 fallback(AC-B).
