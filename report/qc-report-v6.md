## 5차 QCReport 수정 사항 중 재수정 사항
1. 수업 계획실: 시험별 목표 진도를 저장하면 토글로 해당 부분을 계속 띄워줘야 시각적으로 저장이 되어있음을 인지할 수 있습니다. 수정해주세요. 그리고 여유 차시 카운트는 중간, 기말 날짜를 기점으로 넘겨주세요. 1차시험을 이미 봤으면 2차시험 진도 나갈 때는 의미가 없습니다. 그리고 지금 '학기 계획'에서 세부 단원의 최소 차시를 저장했는데 이게 '차시 계획'에 반영이 안됩니다. 세부 단원 차시합에 반영이 되야지요. 이게 중요한 부분입니다. 그리고 지금은 차시계획에서 대표 분반 차시가 나오고 여유 차시를 저장하도록 되어있는데요. 이는 사실 학기 계획에서 해야하는 일입니다. 계획할 때 이번에 진행해야할 차시가 몇차시인지, 여유 차시는 몇인지가 중요하잖아요? 학기 계획으로 옮겨주세요. 그리고 대표 분반 차시를 기점으로 하는건 좋으나, 사실상 1회시험(중간고사), 2회시험(기말고사)를  둘 다 보는 과목이면 전체 차시가 중요한게 아니고 '시험 때 까지 몇차시 남았는지가' 중요한 포인트입니다. 이를  카운트하고 이를  계획할 수 있게 하는게 중요합니다. 반영해주세요.

2. 진척도: 진척도의 연체 예정 차시는 왜 다른 컴포넌트 처럼 페이지 별로 나눠서 띄워주지 않나요? 수정해주세요.

3. 출결 관리: 교외체험학습이 별도 탭으로 승격된건 좋습니다. 그러나 현재는 교외체험학습의 경우 사유의 비고란에 '체험학습'이 적히지 않습니다. 이게 적혀야 정리가 더 쉬울 것입니다. 그리고 월별, 학생별 검색을  할 때도 단순히 월, 학생 이름으로 검색하는게 아니라 사유 등을 기준으로도 검색이 가능하게 해주세요.

4. 공지실: 다 좋아요. 그런데 개별 공지 쓴 것들도 별도 요소로 관리해서 페이지 별로 관리할 수 있게 해주세요. 지금은 두 개의 개별 공지를 쓰면 내용이 띄어쓰기로만 구분되고 합쳐집니다. 이렇게 하지말고 개별 페이지로 분리해달라는 의미입니다. 마치 전체 공지 내용처럼.

5. 학생 안내 페이지: 여전히 영양이 안나옵니다. 왜죠? json 파싱이 안될리는 없을텐데. 납득 가능한 이유를 설명해야 할겁니다. 그리고 칼로리를 마지막 열에 넣고 영양을 중앙열에 넣어주세요. 글자수 배치상  그게 나을 것 같습니다. 그리고 교사의 오늘의 학교에만 있던 기능인 캘린더 터치 시 모달 창 띄우는 기능을  학생 안내 페이지에서도 가능하게 합니다. 교사와 마찬가지로 메모나 일정을 추가할 수 있고 이는 다른 학생들의 캘린더에서는  절대 보이지 않습니다.

6. 오늘의학교: 메인 홈에서 보는 오늘의 학교도 대표 이모지로 꾸며지면 좋겠네요. 그리고 현재는 모바일로 접속할 시 최초 진입이 오늘의 학교 인건 좋으나 아예 메인 페이로 접근도 막혀있습니다. 이를 해결하시오. 그리고 모달로 오늘 해야 할 일 뜨는 것 외에도 페이지 최상단에 오늘 해야 할 일을 메인 페이지 처럼 계속 띄워주세요. 그리고 행동특성 역시도 관찰 기록처럼 담임반 학생들 중 한 명을 콕 찝어서 랜덤으로 기입할 수 있도록 정해주세요. 그리고 기록 버튼을 눌렀을 때 해당 학생이 토글로 선택까지 되어있게 링크가 되어야 합니다. 그리고 행동특성과 관찰 기록에 학생을 랜덤으로 뽑는건 완전 랜덤이 아니라 관찰 기록이 적은 학생들 중에 랜덤으로 뽑아서 누적되면 골고루 기록이 되도록 하는것입니다.
