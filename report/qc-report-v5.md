## 4차 QCReport 수정 사항 중 재수정 사항
1. 수업 계획실: 학기 계획에서 대단원 번호를 입력하고 대단원 명을 기록하면 어차피 해당 대단원 이름은 공통입니다. 그 뒤에 다른 세부단원을 기입할 때 해당 대단원 숫자를 넣으면 자동으로 채워지게 해주세요. 대단원도 같고 중단원 번호도 같으면 또 자동으로 채워주세요. 소단원은 무조건 다 다르기 때문에 자동으로 채우지 않습니다. 또한 학기 계획에서 현재까지 저장된 총 차시 수를 세주세요. 이 값이 대표 분반으로 뽑아낸 차시와 같아지는지 체크해야합니다. 이는 강제 사항은 아닙니다. 다르다는 사실을 넌지시 알려만 주세요. 그리고 맨 위에서 여유 차시를 기입하게 해줍니다. 여유 차시는 말그대로 여유를 남기는 차시입니다. 이를 숫자로 넣으면 세부 단원에서 기입한 차시수와 여유 차시 숫자를 합하여 대표 분반으로 뽑아낸 차시와 같다면 안내가 사라집니다. 이렇게 기입이 완료가 되면 차시 계획에서는 기획된 순서대로 자동으로 차시가 채워져서 저장이 됩니다. 다만 이는 수정이 가능합니다. 여유 차시를 배정했다면 차시 옆에 여유 차시로 등록하기 버튼을 두어 해당 차시를 여유차시로 띄워둘건지를 체크하게 합니다. 해당 버튼을 누르면 해당 차시부터 맨 뒤 차시까지 넣어놨던 단원 코드, 수업내용, 핵심개념이 다음 차시로 이관되어 저장됩니다.

2. 진척도: 현재 진척도는 차시 기반입니다. 차시가 수행이 되었는지를 체크하는 기능입니다. 이는 의미가 없습니다. 수정합니다. 제 의도는 수업 계획실에서 계획한 단원 진도 계획과의 일치도를 보는겁니다. 그래서 해당 기능은 수업 계획실에서 차시 계획까지 저장된 과목이 아니면 활성화 되지 않습니다. 계획된 차시의 단원코드를 기점으로 진척도에서는 실제 수업이 어느 단원의 진도를 나아가고 있는지 지금처럼 체크합니다. 이렇게 체크된 단원 진도와 수업 계획실에서 기입한 시험별 목표 진도와 진도율을 비교합니다. 그말인 즉슨, 지필평가를 보지 않는 과목은 시험까지 진도율을 표기할 필요가 없다는 의미입니다. 실제 수업 후 차시 기입은 똑같이 하나 시험을 맞춘 진도율 체크 기능은 필요없기 때문입니다.

3. 담임교실: 담임 교실로 진입하면 일단 가장 첫 컴포넌트인 자율진로활동 컴포넌트로 먼저 라우트를 옮겨주세요.

4. 출결 관리: 여전히 교외체험학습 사후보고서가 오늘 입력, 월별, 학생별 검색, 미제출 탭 아래에 계속 중복되게 들어가있습니다. 별도 탭으로 승격합니다. 위치는 오늘 입력 다음입니다. 그리고 교외체험학습 등록으로 이름을 수정합니다. 그 외에는 그대로 두되 에스컬레이션 재계산 버튼은 왜 필요한지 궁금합니다. 무슨 의미인지 모르겠네요. 그리고 이렇게 기록된 교외체험학습 역시 인정 결석이므로 출결 검색에서 같이 보여야합니다. 미제출 신고서에도 같이 잡혀야합니다. 이럴거면 그냥 테이블을 합치는게 나을 수도 있겠네요.

5. 공지실: 현재는 교사 한마디에서 개별공지도 쓰고 전체 공지도 씁니다. 좀 불편한 것 같아요 쓰는 칸을 분리해주세요. 개인별 공지 쓰는 란은 학생을 토글로 골라서 적을 수 있습니다. 만약 몇명 에게만 공통된 내용을 쓰고 싶은 경우에는 토글로 학생을 고르고 추가 버튼을 통해 목록을 만들어 한번에 개인별 공지를 등록할 수 있습니다.

6. 학생 안내 페이지:  시간표에서 선택과목을 학생이 기입했을 때 글씨의 색상을 다르게 하여 선택과목과 공통과목을 나눠서 인식할 수 있게 해주세요. 오늘 급식이 날짜가 바뀌었는데도 바로 안바뀝니다. 이를 수정해주세요. 또한 현재 영양 성분이 제대로 표기가 안됩니다. neis api로 호출하면 json 데이터 중 "NTR_INFO":"탄수화물(g) : 99.7<br/>단백질(g) : 34.7<br/>지방(g) : 12.1<br/>비타민A(R.E) : 217.0<br/>티아민(mg) : 0.3<br/>리보플라빈(mg) : 0.5<br/>비타민C(mg) : 17.6<br/>칼슘(mg) : 141.4<br/>철분(mg) : 4.5" 형태로 데이터가 들어가 있습니다. 이를 표기해주세요.

7. 오늘의학교: 넛지는 해결될 때 까지 오늘의 학교 라우트에 진입할 때마다 떠야합니다. 그리고 다음에 하기를  누르니까 상단에 넛지 알림 표기도 없어졌습니다. 모달 창이 꺼지는거지 맨 위에 넛지 알림은 그대로 존재해야합니다. 그리고 오늘 급식의 메뉴가 글자 길이에 따라 너비가 조절이 안되서 글씨가 다 망가집니다. 표 크기를  동적으로 조절하건 아니면 표 표기 방법을 수정하건 해주세요. 다가오는 학사일정 상담 기능에서는 과거의 일정이 더이상 표기가 안됩니다. 수정헤주세요. 그리고 해당 캘린더에 메모 기능을 추가합니다. 이는 모든 캘린더에 추가되는 기능은 아니고 해당  오늘의 학교에서만 보입니다. 동작은 캘린더의 특정 날을 누르면 모달로 해당 날의 정보와 일정이 촤르르 뜹니다. 모달 하단에 일정 추가하기 버튼이 나오고 버튼을 누르면 해당 날의 일정을 메모처럼 추가할 수 있습니다. 다시 얘기하지만 이렇게 추가된 일정은 오직 오늘의 학교 캘린더에서만 보입니다. 

8. 상담실: 상담 슬롯을 개설하고 실제로 예약이 잡힌 후에는 상담일지가 작성되어야 합니다. 이를 오늘의학교 넛지에 추가합니다.

### '동아리실' 수정 방향
1. 기존 동아리실을 독립 컴포넌트로 격상합니다. 이 역시 동아리 관련 컴포넌트들의 허브 역할을 맡습니다. 하위 컴포넌트: 동아리 개설, 동아리 배정, 동아리 활동 계획, 동아리 활동 입력, 생기부 작성

2. 지금 제가 일일이 세부 기능을 적기 어렵습니다. 기존 독립 컴포넌트(세팅실, 교실, 담임 교실)에서 개발했던 내역들을 검토하고 유사하게 풀어나갈 수 있는지 확인합니다. 이에 맞추어 deep-interview를 통해 구체화합시다.

#### 향후 계획
- 동아리실까지 완료된 후 교무실, 통계실, 인쇄실까지 정리가 되면 메인 라우터에 이미 독립 컴포넌트아래 하위 컴포넌트로 흡수된 컴포넌트들이 난잡하게 널브러져 있습니다. 다 지우고 앞선 독립 컴포넌트 하에서 접근하도록 레이아웃을 바꿉니다.
