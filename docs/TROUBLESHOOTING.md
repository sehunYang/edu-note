# 문제 해결

먼저 앱 안 **세팅실 → 시스템 상태**를 열어 보세요. 무엇이 켜져 있고 무엇이 빠졌는지
한 화면에 나옵니다.

---

## 배포가 실패했어요 (Vercel이 빨간색)

### "DB 접속 정보가 없습니다 … Redeploy 하세요"

Supabase 연결이 아직 준비되지 않은 상태에서 빌드가 시작된 경우입니다.
**Vercel → Deployments → 맨 위 항목 → Redeploy** 를 누르면 대개 해결됩니다.

> 이 오류는 **일부러** 배포를 멈춘 것입니다. 그냥 넘어가면 데이터베이스가 빈 채로
> 앱이 떠서 모든 화면이 오류를 내고, 원인을 알기 어려워집니다.

### 그 밖의 빌드 오류

Vercel 배포 로그의 마지막 20줄을 복사해
[Issues](https://github.com/sehunYang/edu-note/issues)에 남겨 주세요.

---

## 로그인이 안 돼요

### "메일 발송 한도에 걸렸습니다"

**Supabase 무료 프로젝트의 내장 메일은 시간당 2통**입니다. 로그인 링크를 두세 번
연달아 요청하면 바로 걸립니다. 최대 1시간 기다렸다가 다시 시도하세요.

자주 걸린다면 Supabase 대시보드 → **Project Settings → Authentication → SMTP Settings**
에서 개인 SMTP(Resend·Gmail 등)를 등록하면 이 한도가 사라집니다. 필수는 아닙니다.

### 로그인 메일이 안 와요
- 스팸함을 확인하세요.
- 설치 6단계(**설정 완료하기**)를 마쳤는지 확인하세요. 안 했다면 앱 주소 뒤에 `/setup`
  을 붙여 접속하면 그 화면이 나옵니다.
- 위의 시간당 2통 한도에 걸렸을 수 있습니다.

### 링크를 눌렀는데 "로그인에 실패했습니다"

**가장 흔한 원인: 링크를 요청한 브라우저와 다른 브라우저에서 열었을 때입니다.**
보안상 로그인 링크는 **요청한 그 브라우저에서만** 열립니다. 컴퓨터에서 요청하고
휴대폰 메일 앱에서 눌렀다면 실패합니다.

→ 링크를 열려는 기기에서 다시 요청하세요. 휴대폰에서 쓰실 거면 휴대폰 브라우저로
앱에 접속해 로그인 링크를 받으시면 됩니다.

그 밖의 원인
- 링크가 만료됐습니다(발송 후 1시간). 새로 받아 주세요.
- 이미 한 번 사용한 링크입니다. 링크는 1회용입니다.

### "등록된 교사 계정이 아닙니다"
`ALLOWED_EMAIL` 에 적은 주소와 로그인에 쓴 주소가 다릅니다.
**Vercel → 프로젝트 → Settings → Environment Variables** 에서 값을 확인하고,
고쳤다면 **Deployments → Redeploy** 를 해야 반영됩니다.

### `/setup` 이 404 예요
이미 설치가 끝났다는 뜻입니다. 한 번 쓰고 닫히는 화면입니다.
로그인이 여전히 안 되면 위 항목들을 확인하세요.

---

## 학사일정·급식이 안 나와요

**세팅실 → 시스템 상태 → 나이스 연동**이 "꺼짐"이면 인증키가 없는 것입니다.
[나이스 개방포털](https://open.neis.go.kr)에서 무료로 발급받아 같은 화면에서
등록하세요.

"켜짐"인데도 안 나온다면 **세팅실 → 학사일정**에서 동기화를 다시 실행해 보세요.
학교가 잘못 지정됐을 수 있으니 **교사 기본** 단계에서 학교 이름을 다시 검색해 보세요.

---

## 시간표가 안 나오거나 이상해요

시간표는 컴시간알리미에서 가져옵니다.

- **학교 이름**은 컴시간에 등록된 정식 명칭과 같아야 합니다(예: `한빛고등학교`).
- **교사 이름**도 컴시간에 등록된 그대로여야 합니다.
- 학기가 바뀌면 **세팅실 → 수업 관리**에서 다시 동기화해 주세요.

컴시간은 공식 API가 아니라, 사이트 구조가 바뀌면 일시적으로 멈출 수 있습니다.
그런 경우 수정본을 업데이트로 보내드립니다.

---

## 알림(푸시)이 안 와요

- iPhone은 **홈 화면에 추가한 뒤**에만 알림을 받을 수 있습니다(iOS 제한).
- 브라우저 사이트 설정에서 알림이 차단돼 있지 않은지 확인하세요.
- 브리핑 알림은 **수업일 아침**에만 발송됩니다. 학사일정이 동기화돼 있어야 수업일을
  판단할 수 있습니다.

---

## 앱이 갑자기 느려지거나 멈췄어요

Supabase 무료 플랜은 **7일간 아무 접속이 없으면** 데이터베이스를 일시정지합니다.
Edu_Note는 매일 도는 작업이 있어 보통은 정지되지 않지만, 정지됐다면
[Supabase 대시보드](https://supabase.com/dashboard)에서 **Restore** 를 누르면 됩니다.

---

## 데이터를 옮기거나 지우고 싶어요

- **백업**: 세팅실 → 시스템 상태 → 백업 내려받기 (JSON 한 파일)
- **완전 삭제**: Supabase 프로젝트를 삭제하면 모든 데이터가 사라집니다.
  Vercel 프로젝트와 GitHub 저장소도 각각 삭제하세요.

---

## 그래도 안 될 때

[Issues](https://github.com/sehunYang/edu-note/issues)에 남겨 주세요. 이렇게 적어 주시면
훨씬 빨리 해결됩니다.

- 어떤 메시지가 나왔는지 (화면 사진이 가장 좋습니다)
- **세팅실 → 시스템 상태** 화면 사진

> 화면 사진에 학생 이름이 보이면 가려서 올려 주세요.
