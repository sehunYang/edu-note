# 설치 안내

Edu_Note를 선생님 계정에 설치합니다. **약 10분**, 터미널이나 코딩은 필요 없습니다.

---

## 미리 준비할 것

| 준비물 | 설명 |
|---|---|
| **GitHub 계정** | 무료. 이메일만 있으면 가입됩니다 → [github.com/signup](https://github.com/signup) |
| **Vercel 계정** | 무료. 위 GitHub 계정으로 바로 로그인됩니다 → [vercel.com](https://vercel.com) |
| **본인 이메일** | 로그인할 때 씁니다. 학교 메일도 좋고 개인 메일도 좋습니다 |

> 나이스 인증키는 **지금 없어도 됩니다.** 나중에 앱 안에서 넣을 수 있습니다.

---

## 1단계 · 배포 버튼 누르기

[README의 Deploy 버튼](../README.md#-설치하기)을 누릅니다. Vercel 화면으로 이동합니다.

## 2단계 · GitHub 연결

**Continue with GitHub** → 저장소 이름을 확인합니다(기본값 `edu-note` 그대로 두면 됩니다).

선생님 계정에 앱의 복사본이 만들어집니다. 원본과는 분리된, 선생님 소유의 코드입니다.

## 3단계 · 데이터베이스 만들기

Supabase 항목에서 **Create** 를 누릅니다.

- **플랜**: Free (무료)
- **리전(Region)**: `Northeast Asia (Seoul)` 을 고르면 가장 빠릅니다

이 데이터베이스가 선생님의 모든 기록이 저장될 곳입니다. **선생님 계정 소유이고, 만든
사람도 접근할 수 없습니다.**

## 4단계 · 칸 하나 채우기

`ALLOWED_EMAIL` 에 **본인 이메일**을 넣습니다. 이 주소로만 로그인할 수 있게 됩니다.

> ⚠️ 오타를 꼭 확인하세요. 잘못 적으면 로그인할 수 없습니다.
> (나중에 Vercel 프로젝트 → Settings → Environment Variables 에서 고칠 수 있습니다.)

나이스 인증키는 **여기서 넣지 않습니다.** 설치가 끝난 뒤 앱 안에서 등록합니다
(아래 "나이스 인증키 받기").

## 5단계 · Deploy

**Deploy** 를 누르고 3~5분 기다립니다. ☕

이 시간 동안 앱이 만들어지고, 데이터베이스 구조도 자동으로 준비됩니다.

## 6단계 · 마지막 설정 (붙여넣기 한 번)

배포가 끝나면 만들어진 주소로 접속합니다. **"거의 다 됐습니다"** 화면이 나옵니다.

1. 화면의 링크로 [Supabase 토큰 발급 페이지](https://supabase.com/dashboard/account/tokens)를 엽니다
2. **Generate new token** → 이름은 아무거나(예: `edu-note`) → **Generate token**
3. 만들어진 `sbp_` 로 시작하는 값을 복사해 앱 화면의 칸에 붙여넣습니다
4. **설정 완료하기**

> **이 단계가 왜 필요한가요?**
> 로그인 메일의 링크가 선생님의 앱 주소로 돌아오도록 등록하는 과정입니다.
> 앱이 대신 처리해 줍니다. **토큰은 저장되지 않고 즉시 버려집니다.**
> 이 화면은 한 번 끝나면 다시 열리지 않습니다.

## 7단계 · 로그인

**로그인하러 가기** → 이메일을 넣고 **로그인 링크 받기** → 메일함에서 링크 클릭.

끝났습니다. 🎉

> ⚠️ **링크는 요청한 그 브라우저에서 열어야 합니다.** 컴퓨터에서 요청하고 휴대폰
> 메일 앱에서 누르면 실패합니다. 휴대폰에서 쓰실 거면 휴대폰 브라우저로 접속해
> 링크를 받으세요.
>
> ⚠️ **로그인 메일은 시간당 2통까지입니다**(Supabase 무료 플랜). 연달아 여러 번
> 요청하면 잠시 막히니, 한 번 받은 링크를 먼저 확인해 주세요.

## 처음 로그인한 뒤

**세팅실**이 순서대로 안내합니다.

1. **학년도** — 올해 학년도를 고릅니다
2. **교사 기본** — 이름과 학교를 넣습니다. **학교 이름만 검색하면** 나이스 코드가 자동으로 채워집니다
3. **학사일정** — 나이스에서 한 해 일정과 급식을 한 번에 가져옵니다
4. **학생 명단** — 엑셀에서 복사해 붙여넣거나 CSV 파일을 올립니다
5. **수업 관리** — 컴시간알리미에서 시간표를 가져옵니다

## 나이스 인증키 받기 (선택)

학사일정·급식·이번 주 실제 시간표를 자동으로 가져오는 데 씁니다. 없어도 앱은 정상
동작하며, 일정을 직접 입력해서 쓸 수도 있습니다.

1. [나이스 교육정보 개방포털](https://open.neis.go.kr) 가입
2. **인증키 신청** → 즉시 무료 발급
3. 앱에서 **세팅실 → 시스템 상태 → 나이스 연동** 칸에 붙여넣고 저장

저장할 때 앱이 **실제로 통하는 키인지 나이스에 확인**합니다. 잘못된 키는 이유와 함께
거부되니, 저장됐다면 연동이 진짜로 되는 것입니다.

Vercel 대시보드에 들어갈 필요 없습니다. 언제든 이 칸에서 바꾸거나 지울 수 있습니다.
